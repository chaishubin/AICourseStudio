# PPT 讲解焦点评估样本集

每类至少准备 20 页（覆盖简单、边界与故意歧义样本），由两名标注者独立标记目标对象、允许的父级区域、无焦点区间及事件边界；分歧由第三人裁决。测试 PPT、讲稿、TTS 时间戳和标注 JSON 固定版本，避免模型/输入漂移。

| 类别 | 必含样本 | 正确性标注重点 |
| --- | --- | --- |
| 文字型 | 单栏要点、双栏、重复标题/页眉、跨要点解释 | 目标 shape ID；多句共享焦点；页面装饰文字不可选 |
| 图文混合 | 文本框加插图、插图旁说明、讲稿只解释图像含义 | 可定位说明框；无法解析图像时允许父级区域或无焦点 |
| 图表 | 柱状/折线/饼图、图例、轴标签、多个系列 | 目标数据系列/标签；全图区域作为可接受退化目标；相似系列歧义 |
| 公式 | 行内公式、分步推导、上下标、多个公式并列 | 公式整体或可解析公式项；讲解“因此/所以”时的持续焦点 |
| 复杂布局 | 分组元素、重叠卡片、流程图、自由排版、含图片文本 | 逻辑分组父级、坐标裁切/遮挡、跨区真实切换 |

## 报告指标

- **自动接受率**：无需人工干预、系统直接接受的焦点事件数 / 全部可判定事件数；无焦点安全退化单独计数。
- **焦点定位准确率**：接受事件中目标精确命中标注对象的比例，同时报告父级区域可接受命中率。
- **时间边界误差**：系统事件起止点相对标注的绝对误差，报告均值、P95 和词级/句级时间戳分层结果。
- **错误指向率**：指向错误对象的事件数 / 全部输出焦点事件数；无焦点不算错误指向。
- **平均人工干预次数**：每节课实际编辑/确认的事件数，并报告人工分钟数作为辅助值。

总表还要按五类 PPT 分层报告自动通过率、退化比例、异常清单、建议人工复核片段；不得以覆盖率替代准确性指标。
