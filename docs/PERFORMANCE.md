# 性能调度与耗时定位

页面分析默认最多并发 3 个请求；讲稿仍按页顺序生成，以保留前一页的承接关系。页面分析和讲稿分别缓存，内容、上下文、提示词或模型变化后失效。讲稿缓存包含前一页讲稿，因此上游内容变化会使依赖它的后续页重新生成。

TTS 使用持续补位的工作池，默认最多 5 个请求在执行。取消生成后不再分派剩余请求。已经发出的网络请求仍受服务商接口超时约束。

后台任务默认使用 2 个工作线程，可重叠模型、配音等网络等待。同一任务的执行互斥；视频合成、包装和 PPT 页面渲染共用进程内渲染锁，避免多个重型渲染同时争抢 CPU 和内存。部署多个服务进程时，这个锁不跨进程，应由部署层控制总渲染并发。

可用环境变量调整并发，重启服务后生效：

| 变量 | 默认值 | 范围 | 用途 |
| --- | --- | --- | --- |
| `PAGE_ANALYSIS_WORKERS` | 3 | 1–8 | 单个任务的页面视觉分析并发 |
| `TTS_CONCURRENCY` | 5 | 1–16 | 单个配音批次的持续并发 |
| `CONVERSION_WORKERS` | 2 | 1–4 | 后台任务工作线程 |

这些并发可能叠加，需结合账号的请求额度调整。CPU 空闲而网络阶段较慢时，优先观察接口延迟和限流，再增加对应并发。内存使用率低本身不是瓶颈。

AI 自动质检在独立的 2 线程池中执行，不阻塞草稿展示。预览页自动刷新质检结果。用户修改讲稿后，旧内容的质检会标记为过期；新审查结果不被更早启动的任务覆盖。服务重启后中断的质检可手动重试。

完整视频保留未包装的正文，切课从这个正文精确提取，复用已渲染的字幕和重点标记。为了准确处理非关键帧边界，切课仍会进行 FFmpeg 编码，不采用近似关键帧切分。无转场包装且 H.264/AAC 参数、时间基和编码附加数据一致时，复制视频流并重新拼接音频，消除每段 AAC 编码延迟；不匹配或输出时间轴校验失败时回退到编码路径。带转场的包装保留滤镜处理。

包装可直接读取正文的时间范围，在最终编码中完成分段与包装，省去中间分段文件的编码。片头、片中、片尾使用任务内的内容缓存，素材、文字、样式或编码配置变化后重新渲染。

## 查看细分耗时

任务输出目录保存 `performance.json`，配音片段和切课目录也可能有各自的报告。登录后可通过 `/api/task-performance/<task_id>` 查看当前账号有权访问任务的计时。报告不记录讲稿、提示词或凭证。

主要指标包括：页面分析请求和墙钟时间、讲稿请求、教案课程设计、插图、PPT 创建、配音请求及缓存处理、音频合并、渲染资源等待、正文编码、包装及切课。每项包含调用次数、失败次数、累计耗时和最近一次耗时。

报告按调用累计，包含重试和后续重新生成。并发请求的累计时间可能超过对应阶段的墙钟时间；嵌套指标不能相加作为总耗时。`stage_timings` 用于查看粗粒度阶段，同一次媒体生成中多次进入视频阶段会累加记录。

先用相同课件、声音、字幕和包装配置做前后对比，再判断收益；短静态样本的提速不代表整套含动画、配音和质检课程的提速。

## 包装重复编码优化验证（2026-11-06）

片中转场直接在最终 FFmpeg 编码中读取正文范围，不再生成并重编码临时正文切片。独立分段加短片头同样直接读取未包装正文，仅编码一次。音频在每次拼接前按视频帧时间补齐或裁剪，避免 AAC 尾部填充累积为同步误差。带淡入淡出的流程仍保留一次完整编码；未启用局部关键帧拼接。

任务输出目录的 `.packaging_cache` 缓存包装视频，键包含文字、选项、编码设置及素材内容 SHA-256。失败的渲染不会发布缓存；改变素材或配置会重新渲染。

本机样本为 12 秒动态正文、24fps、真实烧录 SRT、定时音频标记；两轮交替顺序取中位数。只计包装阶段，不含正文及包装卡片素材创建。切片基线与优化路径使用相同的时间轴修正和最终合成器。

| 场景 | 基线 | 优化后 | 耗时降低 |
| --- | ---: | ---: | ---: |
| 540p，片中卡片，无淡入淡出 | 1.74 秒 | 1.35 秒 | 23% |
| 540p，片中卡片，0.35 秒淡入淡出 | 2.98 秒 | 1.68 秒 | 44% |
| 1080p，片中卡片，0.35 秒淡入淡出 | 6.78 秒 | 3.86 秒 | 43% |
| 540p，兼容视频流直接拼接，对比完整编码 | 1.24 秒 | 0.59 秒 | 52% |

抽样画面的最大平均像素差小于 1/255；快速复制路径的正文抽样解码帧与源文件逐像素一致。定时音频标记相对预期位置最大偏差约 0.17 毫秒，优化路径与切片基线未测出标记偏移差。另验证短片头、缓存复用与失效、取消后保留已发布视频，以及不兼容流和异常输出时间轴的回退。

原始数据见 [packaging-benchmark.json](packaging-benchmark.json)。短样本结果不能代表整套课程的端到端提速。复测命令：

```sh
.venv/bin/python -m pytest tests/integration/test_packaging_single_pass.py -q -s
```
