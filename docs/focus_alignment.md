# 字幕与讲解焦点自动对齐

焦点规划版本：`FOCUS_CUES_VERSION = 8`。

## 数据流程

1. 从 PPT 提取稳定的 shape ID、文字和归一化坐标。
2. 建立本页概念索引：中文标题、括号内英文名称、缩写及显式 `aliases`。
   有显式 `parent_id` 时优先使用，否则按列位置及垂直距离关联标题和说明。
   位于页面顶部的栏目标题也可以是概念，不能仅按纵坐标排除。
3. 用讲稿字符偏移定位字幕所在的完整句子。字幕宽度产生的断行不会把
   整页文字引入局部匹配，也不会通过模糊搜索混淆重复句子。
4. 明确概念优先；说明文字通过局部词句匹配进入候选。
   模型注释只提供有限的释义证据，不能推翻当前句子明确提到的概念。
5. 用 Viterbi 在候选和无焦点状态间规划整页序列，同一知识点的连续性
   是软约束。允许返回前面的概念，禁止跨页继承和无证据继承。
   比较两个明确概念时可以产生多个 `target_ids`。
6. 总结、下一页预告和无法消除的歧义自动恢复整页视图。
   不要求用户确认或修正；异常记录包含自动处理结果。
7. 按原字幕/TTS 时间生成独立焦点事件，预览和视频导出共享此轨道。

## 防止错误复发的边界

- 不把页面 `title` 或完整讲稿当作当前句子的词袋。旧项目的 `title`
  可能实际上是讲稿的开头摘要。
- 英文名称不会稀释中文精确术语；短缩写须匹配完整英文 token。
- 保存的 `source=llm` 和模型自报的置信度不等于正确证据。
  `confidence_kind=evidence_score` 表明数值是规则证据分，而非统计正确率。
- 保存和导出时重新校验自动目标；字幕拆分后再次校验，防止整段注释
  被直接复制到所有字幕；前端带回的旧自动轨道不能覆盖新的规划结果。
- 时间轴往返保留模型来源、知识点、决策证据，避免每次保存改变释义判断。
- 合并事件取最低证据分，不能把弱延续包装成精确术语级别的可信度。
- 已有人工选择仍可保留，但自动生产流程不依赖人工选择。

## 时间与缓存

对齐修复不改变完整覆盖讲稿的字幕文字、已有时间戳或音频文件。
新配音继续使用 TTS 分段的真实音频时长；有通过音频哈希、全文和单调性
校验的服务端时间戳时优先使用。没有字级边界时使用真实分段边界，不伪造
字级精度。本次没有增加需要下载模型的强制对齐服务。

旧预览在版本迁移时自动重新规划，并重建自动焦点事件；人工区间叠加在
自动事件上。已知时间不足时保留无时间的规划，等待实际配音产生时间轴。

## 验证

真实 PLC 课程第二页作为固定回归样本：

- 引入梯形图、指令表、逻辑功能块图时分别对应各自标题。
- 说明组成、操作码/操作数、数字逻辑门时对应各自说明。
- 补充评价延续当前知识点，总结及下一页预告保持无焦点。
- 保留全部 12 条原字幕文字和原配音时间。

`tests/unit/test_focus_alignment.py` 另覆盖：中英文与缩写、拆分到词中间的
字幕、回顾跳转、左右分栏、同名歧义、部分模型输出、模型释义往返、
删除目标后的时间保留、几何校验、多目标比较、缓存配音复用、保存旧轨道
的自动修复及人工区间兼容。

现有程序以文本和 PPT 几何结构为定位证据。图片中的图形若没有文本锚点，
以及讲稿与当前页实际内容不符的情况，仍可能自动恢复整页；覆盖率不能
作为准确率。本页级实现没有加入图片 OCR 或视觉模型。
